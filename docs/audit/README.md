# Практическая работа №19 — SEO и аналитика PCFORGE

> Все показатели Lighthouse и Core Web Vitals заполняются только после реальных измерений. Вымышленные оценки в отчёт не добавляются.

## 1. Проект и окружение
- Проект: PCFORGE — конструктор компьютера.
- Стек: React 19, TypeScript, Vite, Firebase Authentication, Cloud Firestore, Docker, nginx.
- Проверка: production-сборка в Docker, HTTPS, окно инкогнито.
- Адрес: https://pcforge.localhost:8443/.
- Проект не опубликован в интернете, поэтому полевые данные CrUX для локального домена отсутствуют.

## 2. Страницы и архитектура
PCFORGE — SPA на React/Vite (CSR). Разделы переключаются состоянием React и не имеют отдельных URL. Поэтому Lighthouse Navigation и поисковые роботы видят один корневой URL. В sitemap включена только реально существующая страница /.

## 6. Найденные особенности и исправления
Первые два пункта выявлены по исходному коду, а не по Lighthouse. Фактические проблемы автоматического аудита нужно добавить после запуска.

| № | Проблема / ограничение | Влияние | Сложность | Приоритет | Решение |
|---:|---|---|---|---|---|
| 1 | CSR: содержимое и метатеги разделов появляются после выполнения JS | Высокое для SEO | Высокая | Высокий | Зафиксировано; SSR/пререндеринг требует изменения архитектуры |
| 2 | Разделы не имеют отдельных URL | Среднее для SEO | Высокая | Средний | Зафиксировано; отдельные SEO-страницы требуют маршрутизации |
| 3 | Дублирующийся meta robots в локальном архиве | Низкое | Низкая | Низкий | Оставлен один тег |
| 4 | У главного изображения не были заданы размеры и приоритет | Среднее для LCP/CLS | Низкая | Средний | Добавлены width/height, fetchPriority=high, decoding=async |
| 5 | Не хватало ARIA-семантики навигации и skip-link | Среднее для Accessibility | Низкая | Средний | Добавлены aria-label, aria-current, aria-expanded, aria-controls, skip-link |
| 6 | Изображения карточек не имели явных размеров | Низкое/среднее | Низкая | Средний | Добавлены width/height, loading=lazy, decoding=async |
| 7 | Нет фактических Lighthouse / Performance отчётов | Высокое для полноты отчёта | Низкая | Высокий | Ожидаются реальные замеры в локальном браузере |
