# Практическая работа №19 — SEO и аналитика PCFORGE

> Числовые результаты Lighthouse, Core Web Vitals и PageSpeed Insights заполняются только после фактических измерений. Значения не подставляются заранее.

## 1. Проект и режим проверки

- Проект: PCFORGE — конструктор компьютера.
- Стек: React 19, TypeScript, Vite, Firebase Authentication, Cloud Firestore, Docker, nginx.
- Рендеринг: SPA / CSR (содержимое и динамические метатеги формируются после запуска JavaScript).
- Проверка: production-сборка в Docker, HTTPS, Chrome в режиме инкогнито.
- Локальный адрес: https://pcforge.localhost:8443/.
- По условию практической работы проект не публикуется в интернете, поэтому внешние полевые данные CrUX для localhost недоступны.

## 5. Ручные проверки

| Проверка | Ожидаемый результат | Фактический результат / комментарий |
|---|---|---|
| html lang | ru | Указан в index.html |
| title и description | Уникальны для каждого раздела | Обновляются React после запуска JavaScript |
| canonical | Адрес текущего раздела | Обновляется React |
| robots | Публичные разделы index, follow; профиль noindex, nofollow | Проверить в Elements после загрузки |
| Open Graph / Twitter | Title, description, URL и изображение | Начальные значения в index.html, динамические URL обновляются React |
| robots.txt | Открывается от корня и содержит адрес sitemap | https://pcforge.localhost:8443/robots.txt |
| sitemap.xml | Только публичные URL /, /catalog, /builder | https://pcforge.localhost:8443/sitemap.xml |
| alt изображений | Осмысленный альтернативный текст | У изображений задан alt; подтвердить в Elements |
| Клавиатура | Tab / Shift+Tab, Enter / Space, видимый фокус | Проверить вручную |
| Адаптивность | Нет горизонтальной прокрутки на 320, 375, 768 и 1024 px | Проверить вручную |
| Прямое открытие URL | /catalog, /builder, /profile открываются и обновляются без 404 | Проверить через nginx |
| Network | HTTPS-запросы к Firebase, статус и заголовки ответа | Сохранить скриншот |

### Ограничение CSR

В view-source виден исходный шаблон index.html. Содержимое React и уникальные метатеги разделов появляются после выполнения JavaScript и видны во вкладке Elements. Это ограничение CSR; для выдачи готового HTML поисковым роботам потребуется SSR или предварительный рендеринг. Не выдавать динамическое обновление метатегов за SSR.

## 8. Найденные проблемы и приоритеты

Предварительные проблемы по исходникам; после Lighthouse таблицу дополнить фактическими замечаниями и уточнить приоритеты.

| № | Проблема | Страница | Влияние | Сложность | Приоритет | Решение / статус |
|---:|---|---|---|---|---|---|
| 1 | CSR: содержимое и динамические метатеги появляются после JavaScript | Все | Высокое для SEO | Высокая | Высокий | SSR / пререндеринг остаётся дальнейшим улучшением |
| 2 | Метатеги отдельных разделов динамические | Все | Среднее | Средняя | Средний | Добавлены title, description, canonical, robots и Open Graph URL |
| 3 | Страница профиля содержит пользовательские данные | /profile | Среднее | Низкая | Высокий | Добавлен noindex, nofollow; исключён из sitemap |
| 4 | Доступность с клавиатуры требует ручной проверки | Все | Среднее | Низкая | Средний | Добавлены aria-pressed для переключателей; провести ручной тест |
| 5 | Реальные оценки Lighthouse и CWV ещё не внесены | Отчёт | Высокое для полноты | Низкая | Высокий | Ожидает фактических замеров и скриншотов |
| 6 | Адаптивность требует ручной проверки | Все | Высокое для мобильных пользователей | Средняя | Высокий | Проверить указанные ширины и зафиксировать результат |

## 9. Повторная проверка «было — стало»

| Проверка | Было | Стало | Подтверждение |
|---|---|---|---|
| Адреса разделов | Внутренние состояния без отдельных URL | /, /catalog, /builder, /profile | Проверить прямое открытие и обновление |
