# Скриншоты развёртывания PCFORGE

Сюда добавляются реальные скриншоты из VS Code, Docker Desktop и браузера. Не используйте макеты вместо подтверждений фактического запуска.

Рекомендуемые файлы:

1. 01-project-structure.png — дерево проекта в VS Code: основной проект и отдельный репозиторий PCFORGE-deploy.
2. 02-docker-compose.png — успешное выполнение команды Docker Compose.
3. 03-running-container.png — контейнер pcforge-site в состоянии Up/Running.
4. 04-site-browser.png — открытая главная страница PCFORGE в браузере.
5. 05-firebase-auth.png — работающая регистрация или авторизация (без показа паролей и персональных данных).
6. 06-github-actions.png — успешная проверка GitHub Actions.
7. 07-github-repositories.png — два отдельных GitHub-репозитория.

Скриншоты должны быть сделаны на вашем компьютере после запуска проекта. Перед добавлением проверьте, что на них не видны .env, пароли, приватные ключи, токены и личные данные.
